# MBBS Quiz Preparation System

## Overview

The **MBBS Quiz Preparation System** is a web-based quiz application developed specifically to help MBBS students prepare for examinations through structured and exam-oriented practice tests. This project focuses on test preparation and self-assessment, not on teaching medical theory or providing medical knowledge content.

The system enables students to practice Multiple Choice Questions (MCQs) in a simulated exam environment, helping them improve speed, accuracy, and confidence before professional examinations.

## Purpose of the Project

The primary purpose of this project is to:

- Provide MBBS students with a practice-oriented quiz platform  
- Help students evaluate their exam readiness through mock tests  
- Offer instant scoring and feedback for self-assessment  
- Demonstrate collaborative software development using GitHub  

This system is designed strictly as a **practice tool**, not as a medical learning, advisory, or diagnostic platform.

## Key Features

- User registration and login system  
- Subject-wise quiz selection (e.g., Anatomy, Physiology, etc.)  
- Multiple Choice Questions (MCQs) format  
- Automatic quiz submission and score calculation  
- Result display after each quiz attempt  
- Simple and user-friendly interface
